# YAD Game

Game auto-battler dengan aset dari Google Drive.

## Workflow

### 1. Sync Aset dari Drive
Workflow: Sync Assets from Drive
- Otomatis: Setiap minggu
- Manual: Actions - Sync - Run workflow
- Hasil: assets.zip di Releases

### 2. Build APK (Godot)
Workflow: Build Game APK
- Otomatis: Setiap push
- Hasil: APK di Artifacts
